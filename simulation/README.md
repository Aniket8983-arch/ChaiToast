# SmartWaste 360 — Simulation Service

## ⚠️ IMPORTANT: This is SIMULATED Data

All data generated by this service is **computer-generated** and does **not** come from physical sensors or GPS hardware. Every data point is clearly labeled `data_source: "SIMULATED"` in the database and API responses.

## What is Simulated

| Component | Real Hardware | Simulation Replacement |
|---|---|---|
| Ultrasonic sensor | ESP32 + HC-SR04 | Stochastic fill-level generator |
| Vehicle GPS | Physical GPS module | Waypoint interpolation engine |

## How the Simulator Works

The simulation engine runs as background APScheduler jobs inside the FastAPI backend process.

### Bin Fill-Level Simulation
- Fires every **15 seconds** (configurable via `SIMULATION_BIN_INTERVAL_SECONDS`)
- Each bin's fill level changes by a random delta (-1.5% to +4.5%), weighted to trend upward
- Fill slows as the bin approaches 100% (physical realism)
- Automatically drops to 5% when a collection job completes for that bin
- Triggers `BIN_ALMOST_FULL` alert at 80%, `BIN_FULL` at 95%

### Vehicle GPS Simulation
- Fires every **5 seconds** (configurable via `SIMULATION_GPS_INTERVAL_SECONDS`)
- Active vehicles follow waypoint routes between bin GPS coordinates
- Simulates 30 km/h travel speed
- Triggers pickup events on arrival at bin locations

## Upgrading to Real Hardware

When real ultrasonic sensors are available on ESP32:

1. Update `device.sensor_mode` from `"SIMULATED"` to `"REAL"` in the database
2. The APScheduler simulation job automatically skips that device
3. Configure the ESP32 to send readings to `POST /api/sensors/reading` with `data_source: "REAL"`
4. **Zero frontend code changes required**

## Controls

Simulation can be controlled via the API:
- `PATCH /api/devices/simulation/pause` — Pause all simulation
- `PATCH /api/devices/simulation/resume` — Resume all simulation
- `PATCH /api/devices/simulation/speed` — Set speed multiplier
- `POST /api/bins/{id}/simulate/fill` — Force bin to 85%
- `POST /api/bins/{id}/simulate/collect` — Force bin to 5%
